常见问题

首次使用，应该下载哪个版本？

Windows 用户可选安装版，或用免安装版直接从文件夹运行。Android 用户请选择 APK。

部署前需要准备什么？

准备自己的 Cloudflare 账号、DNSHE 域名和 DNSHE API 凭据。向导会提示你完成浏览器授权和部署。
